# Research KPIs
Swap success rate = successful complete exchanges / all attempts.
Successful swap time = mean/median over successes only, with sample size.
All-attempt service time = duration including aborts, separately reported.
Docking error = pose difference from target.
Insertion force = measured peak axial force.
Station availability = serviceable time / requested time.
Charging throughput = safely charged packs per unit time.
Report failure categories, uncertainties, and hardware/software revision.
