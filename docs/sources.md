# Project sources and scope

1. *Fabrication and Analysis of an Automated Drone Battery Swapping and
   Charging System*, Kenyatta University undergraduate report, January 2025.
   The report describes a two-DOF arm, carousel, Arduino-based cold-swap
   prototype with battery replicas and reports 90 s average swap time and
   60% reliability. Confirm author consent before publishing the full report.
2. `https://github.com/MrMvshv/UAV_Conceptual_Design` — user-supplied example
   of an aerospace GitHub project; **not copied into this repository**.
3. `https://suave.stanford.edu/download/standard_install.html` — user-supplied
   SUAVE installation reference. SUAVE is not a dependency of the arm simulation.
4. `https://creativecommons.org/licenses/by-nc-sa/4.0/` — user-supplied
   CC BY-NC-SA 4.0 reference. This is not automatically the license of
   this repository, its source code, or its university report.

All code in this starter is newly drafted illustrative example code.
It is not authenticated as code used in the historical university prototype.
