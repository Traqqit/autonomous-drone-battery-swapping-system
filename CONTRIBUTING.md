# Contributing
1. Create a GitHub issue describing the hypothesis, design change, or defect.
2. Branch from `main`: `git checkout -b feat/short-description`.
3. Add code, parameter sources, tests, and limitations.
4. Run `python -m unittest discover -s tests -v`.
5. Open a pull request with purpose, methods, test evidence, and screenshots if relevant.
6. Have the other project partner review before merging.

Do not commit credentials, personal identifiers, proprietary third-party CAD,
unlicensed figures, or experimental data without consent.
Never describe synthetic results as physical test measurements.
